# 🗺️ Громадянська війна в росії (1917–1922): інтерактивний квіз за відео та картою

Навчальний вебтренажер з історії для учнів 10 класу. Інтерактив поєднує роботу з історико-географічними картами, відеофрагментами та історичними першоджерелами.

## 📋 Структура та механіка
Квіз складається з **12 послідовних кроків (24 завдань)**, поділених на два хронологічні етапи:
* **Етап 1 (1917–1918 рр.):** від Лютневої революції та проголошення УНР до початку громадянської війни.
* **Етап 2 (1919–1922 рр.):** перебіг воєнних кампаній, український визвольний рух та утвердження більшовицького режиму.

### Як працює кожен крок:
1. **Перегляд відео:** учень переглядає тематичний уривок (для розблокування завдань необхідно переглянути щонайменше 88% фрагмента).
2. **Завдання А (Карта):** визначення та позначення відповідного історико-географічного об’єкта на інтерактивній карті.
3. **Завдання Б (Джерела та постаті):** аналіз документів, уривків універсалів, портретів діячів чи хронології (тести, встановлення відповідностей, шкала часу, відкрита відповідь).

## 💡 Особливості
* **Автозбереження прогресу:** результати зберігаються локально у браузері (`localStorage`), що дозволяє продовжити роботу після перезавантаження сторінки.
* **Робота з джерелами:** документи та портрети можна розгорнути для детального читання та розгляду.
* **Режим учителя:** захищений паролем доступ до всіх кроків та координат для демонстрації на уроці.

## 🖥️ Рекомендації щодо пристроїв
Інтерактив оптимізовано для роботи на **персональних комп'ютерах та ноутбуках** (десктопна версія) для зручного масштабування карт та читання документів.
